
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras usando strings, loops, condicionais, seleção aleatória e entrada de dados do usuário em Python.

## 📝 Tarefas

### 🛠️ Jogo da Forca

#### Descrição
Crie um jogo da Forca onde os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual (formato `_ _ _`).
- Rastrear as tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir mensagens de vitória ou derrota.
